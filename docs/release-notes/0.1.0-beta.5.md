# Fünfte öffentliche Beta

**All & Only Chests 0.1.0-beta.5** gibt Pferde-Inventare wieder frei, damit
angelegte Sättel und Pferderüstungen zuverlässig entnommen werden können.

## Änderungen

- Pferde-Inventare werden nicht mehr fälschlich als unerlaubte natürliche
  Loot-Container behandelt.
- Sättel und Pferderüstungen können nach dem Ausrüsten wieder aus dem Inventar
  genommen werden.
- Die Freigabe gilt für die gesamte Pferdefamilie, darunter Pferde, Esel,
  Maultiere und Lamas.
- Die Schutzregeln für natürliche Strukturcontainer bleiben unverändert.

## Qualitätssicherung

- 57 automatisierte Tests einschließlich eines neuen Regressionstests für das
  Öffnen von Pferde-Inventaren
- vollständiger Gradle-Build mit Java 25
- erfolgreicher Gameplay-Test mit Paper 26.2: Pferd gezähmt, Sattel und
  Pferderüstung angelegt, Inventar erneut geöffnet und beide Gegenstände wieder
  entnommen
- reproduzierbarer Build gegen Paper API `26.2.build.112-stable`

## Aktualisierung von Beta 4

1. Beende den Paper-Server vollständig mit `stop`.
2. Sichere die Weltordner und `plugins/AllAndOnlyChests` gemeinsam.
3. Entferne die alte Beta-4-JAR aus `plugins`.
4. Kopiere `AllAndOnlyChests-0.1.0-beta.5.jar` nach `plugins`.
5. Starte den Server wieder.

Die bestehende Fortschrittsdatenbank wird automatisch weiterverwendet. Ein
Reset oder eine manuelle Datenbankänderung ist nicht erforderlich.

Die zusätzliche `.sha256`-Datei erlaubt es, die heruntergeladene JAR zu
prüfen.
