# Zweite öffentliche Beta

**All & Only Chests 0.1.0-beta.2** behebt einen verbleibenden
Explosions-Edge-Case und schließt die reale Windows-Prüfung ab.

## Änderungen

- TNT- und andere Explosionen erzeugen auch bei Schneeschichten und
  Schneeblöcken keine verzögerten Drops mehr.
- Insbesondere werden die unter Paper beobachteten Schneebälle zuverlässig
  unterdrückt.
- Die interne Plugin-Version wird automatisch mit der Build-Version
  synchronisiert und von `/version AllAndOnlyChests` korrekt angezeigt.

## Getestete Umgebungen

- Minecraft Java 26.2 mit Paper und Java 25 auf macOS
- Minecraft Java 26.2 mit Paper und Java 25 auf Windows 11 x64
- Minecraft Java 26.1.2 mit Paper und Java 25 auf macOS

Auf Windows wurden Pluginstart, bestehende SQLite-Daten, Neustart,
Spielbeitritt und der TNT-/Schnee-Edge-Case erfolgreich geprüft. Die
Datenbank-Integritätsprüfung lieferte `ok`.

## Aktualisierung von Beta 1

1. Beende den Paper-Server vollständig mit `stop`.
2. Sichere Welt und `plugins/AllAndOnlyChests`.
3. Entferne die alte Beta-1-JAR aus `plugins`.
4. Kopiere `AllAndOnlyChests-0.1.0-beta.2.jar` nach `plugins`.
5. Starte den Server wieder.

Die bestehende Fortschrittsdatenbank wird weiterverwendet; ein Reset oder
eine manuelle Migration ist nicht erforderlich.

Die zusätzliche `.sha256`-Datei erlaubt es, die heruntergeladene JAR zu
prüfen.
