# Erste öffentliche Beta

Diese Version ist der erste öffentliche Teststand von **All & Only Chests**.
Das Plugin setzt die bekannte Hardcore-Loot-Challenge für aktuelle
Minecraft-Java-Versionen neu um.

## Enthalten

- 18 spielbare Strukturkategorien
- persistenter Fortschritt pro Struktur und Zielgegenstand
- Strukturauswahl und Detailansichten über `/gui`
- Sidebar oder kompakte BossBar als Fortschrittsanzeige
- Schutz vor gewöhnlichem Block-, Kreaturen- und Umgebungsloot
- Sonderbehandlung für Prüfungskammern, Dörfer und Bastionsruinen
- Admin-Befehle zum Testen und Zurücksetzen

## Kompatibilität

- Minecraft Java 26.1.2 und 26.2
- Paper
- Java 25

macOS wurde ausführlich getestet. Ein vollständiger Test auf einem realen
Windows-System steht noch aus. Bitte sichere vor einem längeren Durchlauf die
Welt und den Ordner `plugins/AllAndOnlyChests`.

## Installation

1. Lade `AllAndOnlyChests-0.1.0-beta.1.jar` aus den Dateien dieses Releases.
2. Lege das JAR im Ordner `plugins` deines Paper-Servers ab.
3. Starte den Server und öffne mit `/gui` die Strukturauswahl.

Die zusätzliche `.sha256`-Datei erlaubt es, die heruntergeladene Datei zu
prüfen.
