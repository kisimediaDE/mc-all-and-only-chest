# Vierte öffentliche Beta

**All & Only Chests 0.1.0-beta.4** korrigiert die Dorf-Challenge für einen
langjährigen Vanilla-Fehler und macht Änderungen am Zielkatalog sicher für
bestehende Spielstände.

## Änderungen

- Die Dorf-Kategorie enthält jetzt 83 statt 89 Ziele.
- White, Black, Gray, Brown und Light Gray Wool sowie Shears werden nicht mehr
  verlangt. Diese Gegenstände kommen ausschließlich in der
  `village_shepherd`-Truhe vor.
- Aufgrund von [MC-170550](https://bugs.mojang.com/browse/MC-170550) kann
  `snowy_shepherds_house_1`, die einzige Vanilla-Dorfvorlage mit dieser Truhe,
  nicht natürlich an ein verschneites Dorf angefügt werden.
- Die Loot Table bleibt als Dorf-Loot klassifiziert. Server mit einem
  Worldgen-Fix oder Fix-Datapack bleiben dadurch kompatibel.
- Beim Start gleicht das Plugin gespeicherte Zielschlüssel mit dem aktuellen
  Katalog ab. Reguläre Funde bleiben erhalten, nicht mehr verfügbare Schlüssel
  werden entfernt und durch eine verkleinerte Liste bereits vollständige
  Kategorien werden automatisch abgeschlossen.

## Qualitätssicherung

- 56 automatisierte Tests einschließlich Upgrade-Szenarien mit bestehenden
  Dorf-Funden
- eigener Regressionstest für 14 regulär gefundene Dorfziele
- vollständiger Gradle-Build mit Java 25
- reproduzierbarer Build gegen Paper API `26.2.build.112-stable`

## Aktualisierung von Beta 3

1. Beende den Paper-Server vollständig mit `stop`.
2. Sichere die Weltordner und `plugins/AllAndOnlyChests` gemeinsam.
3. Entferne die alte Beta-3-JAR aus `plugins`.
4. Kopiere `AllAndOnlyChests-0.1.0-beta.4.jar` nach `plugins`.
5. Starte den Server wieder.

Die bestehende Fortschrittsdatenbank wird automatisch weiterverwendet. Ein
Reset oder eine manuelle Datenbankänderung ist nicht erforderlich. Regulär
gefundene Dorfziele bleiben erhalten; beispielsweise wird ein Stand von
14/89 nach dem Update als 14/83 fortgeführt.

Die zusätzliche `.sha256`-Datei erlaubt es, die heruntergeladene JAR zu
prüfen.
