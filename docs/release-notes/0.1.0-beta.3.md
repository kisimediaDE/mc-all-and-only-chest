# Dritte öffentliche Beta

**All & Only Chests 0.1.0-beta.3** verbessert die Alltagstauglichkeit der
Challenge, behebt mehrere indirekte Itemquellen und erweitert die
Persistenz- und Kompatibilitätstests.

## Änderungen

- Gegenstände aus Strukturtruhen lassen sich wieder normal mit identischen
  Gegenständen stapeln. Veraltete interne Markierungen werden beim
  Spielerbeitritt und bei relevanten Inventaraktionen automatisch entfernt.
- Der mit `/chesthud` gewählte HUD-Modus bleibt über Reconnects und
  Serverneustarts erhalten.
- Natürliche Fischer-Fässer in Dörfern können während der aktiven
  Dorf-Kategorie geöffnet werden. Sie enthalten keinen Strukturloot und
  erhöhen weder Item- noch Kistenzähler.
- Mit `/elytradrop on|off|status` kann der einmalige Drop der natürlichen
  Elytra aus ihrem geschützten Rahmen optional erlaubt werden.
- Selbst hergestellte und platzierte Boote können im Überlebensmodus wieder
  abgebaut und aufgehoben werden; ihre Markierung bleibt über Neustarts
  erhalten.
- Wasser kann natürliche Feldfrüchte, Gras, Blumen, Laubhaufen und ähnliche
  Vegetation weiterhin entfernen, erzeugt daraus aber keine Items. Selbst
  angepflanzte Feldfrüchte folgen weiterhin dem normalen Player-Placed-
  Verhalten.
- Beim Wachstum selbst gepflanzter Bäume werden die ersetzten
  Setzlingsmarkierungen entfernt. Der gewachsene Baum erzeugt dadurch wie
  vorgesehen keine Holz-Drops.

## Qualitätssicherung

- 52 automatisierte Tests für Item-Matching, Varianten, Speicherung,
  Trial-/Bastion-Sonderfälle und die neuen Drop-Regeln
- vollständiger Gradle-Build mit Java 25
- manuelle Spieltests der neuen Boots-, Wasser- und Baumregeln auf
  Minecraft Java 26.1.2 mit Paper
- weiterhin kompatibel mit Paper für Minecraft Java 26.1.2 und 26.2

## Aktualisierung von Beta 2

1. Beende den Paper-Server vollständig mit `stop`.
2. Sichere die Weltordner und `plugins/AllAndOnlyChests`.
3. Entferne die alte Beta-2-JAR aus `plugins`.
4. Kopiere `AllAndOnlyChests-0.1.0-beta.3.jar` nach `plugins`.
5. Starte den Server wieder.

Die bestehende Fortschrittsdatenbank wird automatisch weiterverwendet. Die
zusätzliche Tabelle für HUD-Einstellungen wird beim ersten Start angelegt;
ein Reset oder eine manuelle Migration ist nicht erforderlich.

Bereits unter Beta 2 platzierte Boote besitzen noch keine dauerhafte
Player-Placed-Markierung. Ebenso kann bei einem bereits vor dem Upgrade
gewachsenen Baum die frühere Markierung seiner Setzlingsposition noch
vorhanden sein. Neu platzierte Boote und neu wachsende Bäume funktionieren
vollständig nach den Beta-3-Regeln.

Die zusätzliche `.sha256`-Datei erlaubt es, die heruntergeladene JAR zu
prüfen.
