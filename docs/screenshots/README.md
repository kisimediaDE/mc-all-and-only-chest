## Empfehlungen

- möglichst `1920×1080` oder größer
- nur das Minecraft-Fenster, keinen Browser oder Desktop im Hintergrund
- Minimap, Blockinfo und andere Client-Mod-Overlays nach Möglichkeit ausblenden
- einheitliche GUI-Skalierung und dasselbe Resource Pack verwenden
- Chat nur einblenden, wenn die Meldung Teil des Motivs ist
- keine Serveradresse, Koordinaten oder anderen privaten Angaben zeigen
- PNG verwenden und nicht mehrfach als JPEG komprimieren
